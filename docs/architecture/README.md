# Architecture Decision Records

Architecture decisions are recorded as ADRs.

Status values:

- Proposed
- Accepted
- Superseded
- Rejected

An ADR marked Proposed does not authorize implementation by itself.

## Initial decisions

- ADR-0001: Durable local post-meeting pipeline (Proposed)

Milestone 1.3 implements the provisional session contract with atomic manifest replacement and read-only recovery inspection. ADR-0001 remains **Proposed**.
